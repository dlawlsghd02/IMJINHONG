## 필지 선택 후 속성 자동 조회 — 현재 적용

POINT가 클릭 위치와 일치하는 필지 1건을 선택한 뒤 해당 PNU로 토지임야는 1회, 개별공시지가는 기준연도 생략으로 필요한 페이지를 순차 조회한다.
기존 키/domain과 sandbox JSONP를 사용한다. 지도 이동·BOX 응답·OFF 후 다시 ON만으로는 속성 조회를 시작하지 않는다.
전체 페이지 검증 전에는 최신 연도를 확정하지 않는다. 완료 후 API 반환 자료 내 최대 기준연도를 최신 가용 연도로 표시한다.
두 서비스는 병렬 시작하며 완료된 결과부터 독립적으로 표시한다. 실패와 자료 없음을 구분한다.
새 필지 선택·닫기·OFF·기능 해제는 이전 요청을 무효화하고 iframe을 정리한다. 지도 이동은 선택/진행 중 속성을 유지한다.
OFF 때 이미 완료된 결과는 보존하고 아직 진행 중인 항목은 취소 안내로 바꾼다. ON 시 자동 재요청하지 않는다.

공시지가는 복수 레코드 파서를 재사용한다. 같은 PNU·기준연월·가격·공시일은 기본 화면에서 한 가격으로 요약하고,
갱신일이 다른 원본 레코드는 접을 수 있는 자료 상세에서 각각 표시한다. 값이 미제공된 행은 임의로 묶지 않는다.
기준시점 또는 가격이 다른 행도 임의 대표값으로 선택하지 않는다. 완전 중복만 제거하고 페이지 완전성을 별도로 안내한다.
공부상 면적은 ㎡, 공시지가는 원/㎡다. 메타데이터로 계산한 필수 페이지를 순차 수집하며 실패한 요청은 자동 재시도하지 않는다.
아래 과거 단계의 속성 비활성 기록은 이 절의 현재 동작으로 대체한다.

### 상세 패널 표시

지번을 크게, PNU를 작은 글씨로 표시하고 지목·공부상 면적은 2열 카드로 배치한다.
공시지가는 오른쪽 정렬 큰 숫자와 원/㎡ 단위를 사용하며 실제 반환 기준연월·공시일을 함께 표시한다.
출처·원본 레코드·갱신일·조회 연도 설명·API 메타데이터는 기본적으로 접힌 네이티브 details 영역에 둔다.
부분 조회와 완전성 미확인 경고, 서비스 실패와 자료 없음 안내는 기본 화면에서도 확인할 수 있다.
이 변경은 표시용 그룹화이며 파서의 완전 중복 제거 정책이나 요청·원본 레코드 목록을 변경하지 않는다.
연도별 공시지가 이력을 펼치면 반환 자료를 내림차순으로 표시한다. 펼치기 자체는 별도 API 요청을 발생시키지 않는다.
모바일은 패널 높이를 화면에 맞게 제한하고 내부 내용을 스크롤한다. 실제 브라우저 화면 배치는 별도 확인이 필요하다.

### 역대 가격 수집·캐시·증감률

기본 화면의 최신 가용 가격을 확정하려면 전체 페이지가 필요하므로 선택 직후 필요한 페이지를 순차 조회한다.
이력 펼치기는 기본 조회와 같은 결과/진행 중 요청을 사용한다. 페이지 수는 ceil(totalCount/numOfRows)이며 2개로 고정하지 않는다.
페이지별 PNU·페이지 번호·크기·반환 건수·전체 건수의 일관성을 확인하고 반복된 페이지 내용도 감지한다.
메타데이터 부족, 중간 실패, 반복/모순 응답은 중단하고 확보된 자료만 표시한다. 이 경우 최신 확정·증감률 계산은 보류한다.
응답의 정렬 순서가 최신순이라고 가정하지 않으며 자료가 없는 연도를 생성하지 않는다. 2017년 이전 자료가 없다고 단정하지 않는다.

메모리 페이지 캐시는 지도 인스턴스별, TTL 60초·최대 64페이지이며 키는 PNU/연도 생략 조건/페이지 크기/페이지 번호를 포함한다.
캐시 저장 용량은 조회 페이지 수 상한이 아니다. TTL은 읽기로 연장하지 않는다. 새 선택에서는 유효 페이지를 재사용하고 미확보 페이지만 조회한다.
API 실패 시 정상 확보 페이지는 보존하되 메타데이터 충돌/반복 응답 시 해당 PNU 캐시를 무효화한다. 기능 해제 시 메모리 캐시를 비운다.
서로 다른 시점의 페이지 조회를 서버 스냅샷으로 보장할 수는 없다. 전체 건수 변화 등 감지 가능한 불일치는 중단한다.

통계에는 PNU·연도·월·공시일·가격이 같은 행을 한 번만 사용한다. 갱신일이 다른 원본 레코드는 자료 상세에 모두 보존한다.
다른 기준월·공시일·가격은 별도 행으로 표시한다. 당해/직전 연도 비교 행이 각각 유일할 때만 (당해-전년)/전년×100을 계산한다.
직전 연도 결측, 비교 기준 복수, 가격 미제공, 전년 0원, 수치 범위 초과는 미산출이다. 기준월이 다르면 비교 주의를 표시한다.
증감률은 소수 둘째 자리, 상승 +, 하락 -, 동일 가격 0.00%로 표시한다.
오프라인 회귀: `node --test tests/parcel-offline.test.mjs tests/attribute-probe-offline.test.mjs tests/land-price-history.test.mjs`.
실제 API 재호출과 브라우저 검증은 이번 구현 단계에서 수행하지 않았다.

## BOX 한도 확대 — 현재 적용값

BOX 면적을 최대 2㎢, 페이지 크기를 1,000건으로 확대했다. POINT 줌 17·BOX 후보 줌 15와 기존 요청 제어는 유지한다.
기존 좌표 수·캐시 메모리 예산은 확대하지 않는다. 1,000건 응답 하나가 캐시 피처 예산을 모두 사용할 수 있으며,
좌표 수가 캐시 예산을 넘으면 표시 가능한 완전 응답도 캐시에 저장되지 않을 수 있다.
1,000건 반환만으로 완전 조회를 확정하지 않는다. 전체 건수·페이지 정보를 확인하고 부분 응답은 화면에 안내한다.
확대된 한도의 실제 API 응답과 브라우저 성능은 미검증이다. 아래 과거 단계의 미검증 기록은 해당 작성 시점의 상태다.

# 지적 경계·선택·상세정보

## 상시 ON/OFF 자동 경계 표시 — 개발 환경

개발용 페이지당 자동 BOX 1회 제한과 전송 시도 1/1 안내는 제거했다.
지적도 버튼은 처음에 OFF이며, ON 상태에서만 현재 화면 범위에 필요한 경계를 조회한다.
OFF는 레이어·패널을 숨기고 진행 중 요청·예약을 무효화한다. 완료된 POINT 선택과 패널 내용은 보존한다.
다시 ON 하면 현재 범위의 유효한 완전 응답 캐시를 먼저 확인해 즉시 복원한다. TTL은 연장하지 않는다.
캐시가 만료됐거나 현재 범위와 다르면 기존 조회 조건에 따라 새 BOX를 요청한다.
새 클릭·명시적 패널 닫기·기능 해제는 기존대로 선택을 정리한다. 레이어를 중복 생성하지 않는다.

활성화는 import.meta.env.DEV === true와 VITE_CADASTRAL_AUTO_BOX가 정확히 true 문자열인 조건을 모두 요구한다.
미설정·false는 비활성이고, 프로덕션은 환경변수가 true여도 비활성이다.
기존 키·domain·sandbox·Actions 인증 설정은 변경하지 않았다.

유지하는 내부 제한:
- BOX 후보 줌 15 / POINT 줌 17
- 실제 전송 BOX 지상면적 2㎢ 이하, 응답 최대 1,000건, 첫 페이지만
- 이동 종료 지연 350ms, 최소 요청 간격 1.5초
- 캐시 TTL 60초, 최대 8항목, 피처·좌표 수 예산
- 동일 진행 요청 억제, 오래된 응답 무시, 부분·완전성 미확인 안내
- 자동 재시도·추가 페이지·범위 분할 없음

실패·부분·불명확한 동일 범위를 이동 종료 이벤트만으로 반복 요청하지 않는다.
사용자의 명시적 OFF → ON은 새로운 조회 의사로 처리하되, 기존 캐시·면적·시간 간격 조건은 그대로 적용한다.
정상 완전 응답의 TTL 만료 후에는 사용자 이동이나 다시 ON할 때 새 조회가 가능하다.
JSONP는 논리적 취소이며 이미 전송된 네트워크 요청 중단을 보장하지 않는다.
기존 수동 runManualBoxOnce의 개발 전용 1회 제한은 별개로 유지한다. 자동 검증 중 함께 실행하지 않는다.

로컬 실환경 검증은 별도 승인 후 진행한다.
1. 지적도 OFF 상태에서 서울시청 부근 작은 범위와 Network 기록을 준비한다.
2. ON 후 주변 경계와 건수·완전성을 확인한다.
3. 같은 범위에서 TTL 이내 OFF → ON을 반복하고 캐시 안내·추가 전송 없음을 확인한다.
4. TTL 만료 및 작은 범위 이동 후 새 조회가 1.5초 간격을 지키는지 확인한다.
5. OFF 뒤 이동해도 요청이 시작되지 않는지, 다시 ON하면 새 범위가 표시되는지 확인한다.
6. POINT 선택·패널과 오래된 BOX 응답 무시를 확인한다. 오류 시 자동 재시도하지 말고 OFF로 종료한다.
이번 변경에서는 실제 API 호출·브라우저 자동화·배포를 수행하지 않는다.
## 개발 전용 수동 BOX 1회 검증 경로

`src/dev/parcelBoxProbe.ts`는 main/registry에 연결하지 않는 개발용 모듈이다.
일반 화면 버튼·전역 함수·HTTP API 경로를 추가하지 않는다. import만으로 요청하지 않는다.
Vite 개발 환경에서 명시적인 `BOX_MANUAL_ONCE` 확인을 전달한 호출만 허용한다.
프로덕션 빌드에서는 DEV 검사로 수동 권한을 거부하며, 개발 모듈은 일반 앱에서 import하지 않아 배포 번들에 포함하지 않는다.

수동 검증은 기존 provider.box에 `manual-validation` 실행 목적을 전달한다.
일반 호출은 기존 자동 설정 false일 때 계속 거부한다. 수동 호출만 DEV 조건에서 허용하고,
면적·형식·1,000건·PNU·도형·페이지 검증 및 기존 키/domain/JSONP sandbox를 그대로 거친다.
provider 인스턴스와 개발 모듈 각각 1회 시도만 허용한다. 입력·인증·전송 오류 후에도 자동 재시도하지 않는다.
새 모듈 인스턴스나 페이지 재실행으로 시도 제한을 초기화하는 행위는 추가 요청 승인을 뜻하지 않는다.
자동 스케줄러·지도 이벤트·캐시·레이어는 생성하지 않는다. 결과는 건수·형식·도형 유형·완전성 요약만 반환하며
키·URL·PNU 원문·원본 응답은 반환하거나 로그에 남기지 않는다.

현재 단계에서는 실제 API 호출을 하지 않는다. 별도 승인 후 다음 순서로 1회 검증한다.
1. 기존 Vite 개발 주소와 키/domain 설정 여부를 값 노출 없이 확인한다.
2. 개발자 도구 Network를 먼저 열고 All·기록 상태를 확인한다. 요청 URL·HAR·캡처를 공유하지 않는다.
3. `/IMJINHONG/src/dev/parcelBoxProbe.ts`를 개발 도구에서 import한다. 이 단계에는 API 호출이 없다.
4. 승인된 2㎢ 이하 BOX를 정한 뒤 `runManualBoxOnce`를 명시적으로 한 번만 실행한다.
5. 성공·실패 모두 종료하고 요약과 HTTP 상태만 보고한다. 재클릭·페이지 재실행·추가 요청은 하지 않는다.

개발 주소의 인증 성공은 별도 확인 대상이다. 등록 URL을 domain으로 전달해도 로컬 사용이 자동 허용되는 것은 아니다.
실제 API 검증이 끝나 경로가 불필요해지면 개발 모듈과 provider의 수동 실행 분기만 제거할 수 있다.

## 자동 BOX 경계 표시 1차 보완 — 미실행

POINT의 기존 키·domain 인증 성공은 사용자가 Pages에서 확인했다. 이번 보완은 코드 작성만 진행했으며
타입 검사·빌드·실제 BOX 호출·브라우저 검증은 아직 하지 않았다. 자동 BOX 설정은 계속 false다.
아래 초기 구현 기록보다 이 절의 요청 수명·캐시·확대 수준 설명을 우선 적용한다.

| 설정 | 초기 애플리케이션 운영값 |
| --- | --- |
| POINT 최소 줌 | 17 |
| BOX 후보 최소 줌 | 15 |
| 전송 BOX 지상면적 | 2,000,000㎡ 이하 |
| BOX 페이지 크기 | 1,000건, 첫 페이지만 |
| 이동 종료 지연 / 최소 요청 간격 | 350ms / 1,500ms |
| 캐시 TTL / 항목 수 | 60초 / 최대 8개 |
| 캐시 전체 피처 / 좌표 위치 수 | 최대 1,000개 / 100,000개 |
| 개별 BOX 응답 좌표 위치 수 | 최대 200,000개 |

이 수치는 공식 한도가 아니다. 줌 15라도 화면 면적이 넓으면 요청하지 않으며, PC에서는 줌 17도 제한될 수 있다.
회전 화면의 외접 범위를 4326 BOX로 변환하고 그 BOX의 위도선·경도선으로 둘러싸인 구면 면적을 계산한다.
3857 평면면적 또는 필지 공부상 면적이 아니다. 범위 역전·날짜변경선 통과·표시 투영 범위 초과는 거부한다.

POINT와 BOX는 세대 번호·컨트롤러·상태 문구를 분리했다. 새 클릭·상세 패널 닫기는 POINT만 무효화한다.
지도 이동·화면 크기 변경은 BOX와 예약 타이머만 무효화하고 경계 레이어를 비운다.
기존 선택 필지와 상세 패널, 클릭 위치에 대한 진행 중 POINT 응답은 단순 지도 이동으로 지우지 않는다.
선택 초기화는 새 클릭·패널 닫기·기능 해제 때 수행한다. OFF는 완료된 선택을 숨김 상태로 보존한다.
BOX 안내는 별도 문단을 사용하므로 POINT 로딩·오류·상세정보를 덮어쓰지 않는다.

자동 조회가 추후 승인으로 활성화되면 이동 종료 후 지연, 면적 검사, 동일 범위 캐시 확인, 요청 간격 검사 순서로 진행한다.
간격 대기는 최신 범위 1건만 예약한다. 자동 재시도·추가 페이지·범위 분할은 없다.
완료된 부분/불명확 응답과 실패한 동일 BOX는 즉시 자동 재요청하지 않고 안내한다.
정상 완전 응답은 TTL 내 재사용하며 TTL 만료 후 새로운 사용자 이동/활성화 이벤트에서 다시 조회할 수 있다.
OFF는 레이어·패널 숨김, POINT/BOX 무효화·예약 취소를 수행하며 완료된 선택은 보존한다. 캐시는 TTL 내 재사용을 위해 유지하고 기능 해제 시 비운다.
JSONP는 논리적 무효화만 보장한다. 이미 전송한 네트워크 요청의 중단·과금/사용량 취소와 실제 동시 네트워크 수는 보장하지 않는다.

`features/parcelBoundaryCache.ts`는 지도 인스턴스별 메모리 LRU다. 정확히 같은 전송 BOX·서비스·CRS·페이지 크기를 키로 사용한다.
만료 항목은 캐시 접근 시 제거하고 예산 초과 시 오래된 항목부터 제거한다. 영구 저장과 주기적 갱신 호출은 없다.
피처는 복제하고 PNU/ID를 보존하며 원본 응답·인증정보는 저장하지 않는다.
완전성이 확인되지 않거나 부분 응답인 데이터는 캐시에 넣지 않는다. 피처·좌표 수 제한은 바이트 단위 메모리 보장이 아니다.

BOX 전용 파싱은 전체/현재 건수와 페이지 메타데이터를 확인한다.
- 전체 건수가 반환 개수보다 크거나 여러 페이지이면 일부 반환으로 표시한다.
- 메타데이터 누락·형식 불명확은 완전성 미확인으로 표시한다. NOT_FOUND도 BOX에서는 보수적으로 완전성 미확인이다.
- 건수/페이지 정보가 서로 모순되면 검증 오류로 처리한다.
- 1,000건이 반환되어도 메타데이터가 확인되지 않으면 전체가 반환됐다고 주장하지 않는다.
- 완전 판정은 API 메타데이터 기준이며 현실의 전국 필지 데이터 완전성·최신성을 보증하지 않는다.
POINT의 기존 엄격한 파싱과 단일 후보 선택은 유지한다. 경계 응답이 일부여도 POINT는 독립 요청으로 처리한다.

다음 승인 단계: 타입 검사·빌드 → 작은 BOX의 제한된 실증 → 이동·회전·리사이즈·OFF/ON·캐시·POINT 회귀 → 활성화·배포 별도 승인.

## 현재 상태

2026-11-06 코드 및 문서 작성 단계다. 이번 변경에 테스트·빌드·API 호출·브라우저 검증을 수행하지 않았다.
사용자가 제공한 선행 검증 결과(지적 MultiPolygon/PNU, 토지임야, 2026년 공시지가)를 근거로 작성했다.
선행 셸 응답 검증은 브라우저 CORS·JSONP·서비스 URL 인증을 입증하지 않는다.

지적도는 기본 꺼짐이다. 켜기만 해서는 자동 API 조회가 없다. 줌 17 이상에서 클릭할 때 공식 점조회가 발생하는 구조다.
자동 BOX 조회는 설정과 어댑터 양쪽에서 차단되어 있으므로, 현재는 **선택 필지 강조만 가능하도록 작성**되었다.
화면 전체 경계와 상세 면적·공시지가가 정상 표시된다고 표현하면 안 된다.

## API와 파싱

- 지적: `https://api.vworld.kr/req/data`, `service=data`, `version=2.0`, `request=GetFeature`, `data=LP_PA_CBND_BUBUN`.
  `crs=EPSG:4326`, `format=json`, `errorFormat=json`, `geometry=true`, `attribute=true`, `columns=pnu,jibun`, `page=1`.
  POINT는 `POINT(경도 위도)`, `size=5`; BOX는 `BOX(서경,남위,동경,북위)`, `size=1000`으로 작성했다.
  **BOX의 범위 요청 동작은 실증 전이다.** 공식 문서: https://www.vworld.kr/dev/v4dv_2ddataguide2_s002.do?svcIde=cadastral
- 결과는 `response.result.featureCollection`의 GeoJSON FeatureCollection을 사용한다.
  `record.current/total`, `page.current/size/total`을 검사한다. 누락·중복 PNU·잘못된 도형은 오류이며 추가 페이지는 요청하지 않는다.
  선행 응답에는 CRS 필드가 없었다. 고정 서비스에 명시한 EPSG:4326 요청과 검증된 x=경도/y=위도를 근거로 처리한다.
  CRS가 명시되었는데 다르면 거부한다. 범위·닫힌 링·유한값·좌표변환 후 투영 범위도 검사한다.
  이는 전체 Geometry 위상 유효성 검사나 측량 정확도 검증을 의미하지 않는다.
- 토지임야: `https://api.vworld.kr/ned/data/ladfrlList`, 공식 문서 https://www.vworld.kr/dtna/dtna_apiSvcFc_s001.do?apiNum=128
  선행 응답 봉투 `ladfrlVOList`, 허용 속성 `pnu`, `lndcgrCode`, `lndcgrCodeNm`, `lndpclAr`, `lastUpdtDt`만 결과 객체에 보존한다.
- 공시지가: `https://api.vworld.kr/ned/data/getIndvdLandPriceAttr`, 공식 문서 https://www.vworld.kr/dtna/dtna_apiSvcFc_s001.do?apiNum=25
  선행 응답 봉투 `indvdLandPrices`, 허용 속성 `pnu`, `stdrYear`, `stdrMt`, `pblntfPclnd`, `pblntfDe`, `lastUpdtDt`만 보존한다.
  요청 기준연도는 설정의 2026년이다. 기준월 누락은 미제공으로 표시하며 서로 다른 월/값을 자동 선택하지 않는다.
- 속성 봉투 내부의 목록 포장 경로는 실증 상세가 부족해 PNU 행을 제한된 깊이/노드 수에서 탐색한다.
  실제 브라우저 응답 확보 후 정확한 목록 경로와 메타데이터 위치를 확인해야 한다. 상위 totalCount가 있으면 행 수 일치를 검사한다.
  완전 동일한 허용 속성 중복만 합치며 충돌 중복은 오류다. 개인 소유자 필드는 추출·저장·표시하지 않는다.
  빈 resultCode는 오류로 단정하지 않는다. 기타 API 오류 원문은 표시하지 않는다.
  전송 미검증이므로 두 속성 API의 실제 요청 생성 및 전송은 보류했다.

## 성능·보안과 표시 원칙

설정의 POINT 줌 17·BOX 후보 줌 15, BOX 면적 2,000,000㎡, 경계 1,000건, 점 후보 5건, 이동 종료 지연 350ms, 타임아웃 15초는
공식 서비스 한도가 아닌 초기 앱 운영값이다. BOX 면적 제한은 3857 평면면적이 아닌 구면 면적으로 검사한다.
자동 재시도·자동 범위 분할·추가 페이지·전국 수집은 없다. BOX 활성화 후에도 범위와 동시 요청을 제한한다.
동일 대기 클릭/완료 범위 요청은 중복을 억제하며 지도 이동 시 오래된 경계를 비우고 POINT 선택은 유지한다.

JSONP 콜백은 요청별 UUID와 별도 iframe window에 존재한다. sandbox는 allow-scripts만 허용하고
allow-same-origin은 허용하지 않는다. CSP는 nonce와 공식 `/req/data` 스크립트 경로만 허용한다.
부모는 source, origin=null, 채널, 요청 ID를 함께 확인한다. 완료·오류·타임아웃·무효화 시
타이머, 메시지/abort 리스너, iframe을 정리한다. 무기한 전역 콜백을 남기지 않는다.
이는 네트워크 취소를 보장하지 않는다. 늦은 응답은 세대 검사로 화면 갱신을 막지만 실제 브라우저 동작은 별도 검증해야 한다.
Referrer 정책은 strict-origin-when-cross-origin이다. srcdoc/sandbox의 실제 Referer 및 인증 호환성은 미확인이다.
외부 JSONP 스크립트 실행과 일반 JSON 수신은 다르다. 전체 URL·키·원문 오류·원본 응답을 로그로 남기지 않는다.

상세 패널은 모든 API 문자열을 textContent로 출력한다. 지목 코드가 없으면 명칭만으로 분류하지 않는다.
공부상 면적만 ㎡로 표시하고 도형 계산면적을 대체값으로 사용하지 않는다.
개별공시지가는 원/㎡ 단가다. 기준연월·공시일자·각 자료 갱신일을 분리하며 없는 값은 미제공이다.
연속지적도 기준시점은 응답에 확인되지 않아 미제공으로 표시한다. 소유정보와 개인정보는 이번 범위에서 제외한다.

## 별도 승인 후 검증 순서

1. `npm.cmd run typecheck`, `npm.cmd run build`: 새 코드의 정적 검사와 번들 검증. 오류 수정은 승인 범위 확인 후 진행.
2. 제한된 브라우저 점조회: 공개 필지 1곳, 지적 버튼/줌 제한, 인증/Referer/CSP/JSONP 메시지, PNU·좌표·클릭 일치 확인.
3. 요청 무효화/타임아웃/중복 후보/조회 없음, 기존 검색·마커·일반/위성·좌표 표시 회귀 및 모바일 배치 확인.
4. 작은 BOX 1회 등 호출 수를 별도로 승인받아 범위 문법·축 순서·응답 건수·잘림·개인정보 제외를 확인.
   성공 이후에만 자동 BOX 설정 활성화와 추가 검증을 별도로 승인받는다.
5. 토지임야/공시지가의 공식 브라우저 전송 규격과 실제 CORS 또는 JSONP를 개별 검증한다.
   검증된 방식의 전송 어댑터 구현 승인을 받은 후 면적·지목·공시지가·기준시점의 PNU 연계를 확인한다.
6. 검증 완료 후에만 별도 승인으로 commit/push/Pages 배포 및 배포 Origin 재검증을 진행한다.

향후 지목 분류는 검증된 PNU별 코드 속성을 기존 경계 Feature에 결합하고 스타일 함수만 전환하는 방향이다.
현재는 도형의 지번 접미사나 미확인 값을 지목으로 추정하지 않으며 분류 UI도 노출하지 않는다.
