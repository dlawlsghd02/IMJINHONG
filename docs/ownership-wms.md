# 토지소유구분도 WMS 및 모바일 UI

운영 경로는 V-World 전용 getPossessionWMS 이미지다. key/domain/crs/bbox/width/height/format만
전달하며 표준 WMS 레이어·스타일 파라미터를 추정해 추가하지 않는다.
원본 색상·알파와 opacity 1을 유지하고 최대1024픽셀 이미지에 화면 bbox를 대응시킨다.
최초OFF, 이동 완료350ms 후 갱신, 이동 시작/OFF 시 채움 제거·예약 취소·늦은 이벤트 차단이다.
소유35·지적40·선택50 순서다. 기존 필지 속성·공시지가 요청은 변경하지 않는다.

공식 색상 범례는 미확보다. 기존 PNG의 일부 필지 대조 결과로 잠정 범례를 표시하며
공식 범례가 아니라는 한계와 지도 색상만으로 소유권을 확정하지 말라는 안내를 제공한다. 지번·면적 라벨 및
축척별 표시 제한은 서버 스타일에 따른 미해결 제약이다.
브라우저 이미지 오류만으로 인증 XML·네트워크 실패를 세부 구분하지 못한다.

모바일900px 이하에서 검색·레이어 도구와 범례는 기본접힘, 긴 설명은 도움말이다.
44px 터치높이, safe-area, 하단 스크롤 필지 패널을 사용한다. PC는 도구를 펼친다.
320/375/390/430/768px 조건 테스트는 모의 상태/정적CSS 검사이며 실기기 검증을 대신하지 않는다.

이번 배포는 WMS 및 모바일 변경만 포함한다. 이전 WFS·Worker·필지 소유속성·규제분류
미배포 변경은 작업 트리에 보존하며 함께 커밋하지 않는다.

## 변경 전 512px 구성의 축척·범례 재점검 (2026-11-11, 실제 요청 없음)

ownershipWms/ownershipFeature에는 minZoom/maxZoom/minResolution/maxResolution/minScale/maxScale
표시 조건이 없고 bbox 면적·폭·높이 상한도 없다. 지도 자체의 줌 범위는 존재하지만 소유 WMS만
늦게 표시하는 조건이 아니다. 현재 ImageStatic은 서버 축척 정보를 읽거나 적용하지 않는다.

화면 bbox를 줄이지 않고 요청 이미지의 긴 변만 최대512픽셀로 줄인다. 긴 변 L일 때
요청 해상도 저하 배수는 max(1,L/512), 줌 환산 차이는 log2(max(1,L/512))다.
이는 서버의 실제 표시 임계값이 아니라 클라이언트의 샘플링 차이 계산이다.

|지도 CSS 크기 예시|요청 이미지|해상도 배수|줌 환산 차이|
|---|---|---|---|
|1280×800|512×320|2.5|약1.32|
|390×700|285×512|약1.37|약0.45|
|320×480|320×480|1|0|
|768×900|437×512|약1.76|약0.81|

반올림에 따른 축별 미세 오차가 있다. 위 크기는 지도 영역 예시이며 실기기 화면 전체 크기와
같다고 가정하지 않는다. DPR은 현재 요청 크기에 곱하지 않는다. 512는 이전 소규모 실측값을
기준으로 정한 앱 정책이지 공식 서비스 최대치가 아니다. 서버 허용 크기를 확보하지 못해
1024/2048 또는 DPR 배율로 임의 확대하지 않았다. 타일/분할 요청도 도입하지 않았다.

공식 WMS 상세 문서(apiNum=45)는 공개 조회 도구에서 접근되지 않았고, 공개 검색에서도
토지소유정보의 공식 범례/스타일 색상표/축척값을 확보하지 못했다. 일반 /req/wms나
/req/image의 다른 레이어 문서를 이 전용 엔드포인트의 근거로 대체하지 않는다.
GetCapabilities/GetLegendGraphic 요청은 실제 API 호출이라 이번 범위에서 수행하지 않았다.
따라서 ScaleDenominator·범례 URL의 존재/지원 여부는 미확인이다.

큰 화면의 요청 해상도 저하는 확인됐지만 실기기의 확대 필요 현상 전체를 이것만으로
확정 설명할 수 없다. 동일 bbox·다른 이미지 크기 비교와 축소 상태 응답 픽셀 검증 없이는
서버 축척 제한·빈 이미지·작은 필지의 픽셀 소실·데이터 분포를 구분할 수 없다.
현재 공식 범례 확인중/소유권 주의 문구·모바일 기본접힘·UI 크기·기능 코드는 그대로 유지했다.

다음 실측은 별도 승인 후 동일 bbox의 기존512 요청과 지원 근거를 확보한 크기1종을 비교한다.
각1회, 최대2회이며 자동재시도는 없다. 요청 규격·HTTP·실제 PNG 크기·알파/채움 존재·라벨을
확인하고, 빈 이미지의 디코딩 성공을 색상 표시 성공으로 처리하지 않는다.
공식 범례 조회는 정확한 레이어/스타일 및 서비스 지원 근거 확보 후 별도 승인으로 진행한다.

## 1024px 시험 적용

요청 긴 변 상한과 URL 크기 검증 상한을 1024로 변경했다.
비율은 min(1,1024/max(width,height))로 계산하며 지도 CSS 크기보다 확대하지 않는다.
DPR은 곱하지 않는다. BBOX·CRS·인증·색상·취소·갱신 정책은 유지한다.
예: 1280×800 → 1024×640, 390×844 → 390×844, 320×480 → 320×480.
기존 작은 성공 영역의 512/1024 PNG 비교는 세부 표현 개선 근거이며 축소 상태 해결 근거는 아니다.
색상이 나타나지 않았던 실제 축소 BBOX를 확보하지 못해 이번 추가 API 요청은 수행하지 않았다.
전체 오프라인 테스트 285건, 프런트엔드 타입 검사 및 프로덕션 빌드가 통과했다.
공식 범례 안내는 유지하며 실제 축소 범위 비교 후 배포 여부를 결정한다.

## WMS 잠정 범례 구현 (미배포)

기존 512/1024 PNG의 동일 RGBA 내부점을 지적 POINT로 조회해 도형 내부 포함·PNU·건수와
페이지를 검증한 뒤, 신규 고유 PNU에만 ladfrlList를 조회했다. 기존 8필지와 신규 13필지를
합쳐 독립 PNU 21개를 확보했다. 신규 후보 22개 중 9개는 중복이라 속성을 재조회하지 않았다.
한 곳의 약306m 범위에서 선정한 탐색적 표본이며 전국 대표성이나 공식 범례 정확도가 아니다.

분홍색은 단일 소유구분으로 확정하지 않는다. WMS와 토지임야정보의 시점·분류·도형 차이가
불일치 원인일 가능성은 있으나 확인되지 않았다. 토지임야 lastUpdtDt를 WMS 기준일로 쓰지 않는다.
공유인수만으로 개인·법인 혼합 공동소유를 확정하지 않는다.

ownershipWmsProvisionalLegend는 기존 WFS 자체 ownershipLegend와 분리했다.
견본은 원본 RGB·알파128에 대응하는 rgba(...,0.50196)를 불투명 흰색 받침 위에 표시한다.
지도 배경에 따라 실제 합성색이 달라질 수 있다. 텍스트나 테두리에 전체 opacity를 적용하지 않는다.
기존 details/summary·PC 펼침·모바일 접힘·OFF 숨김·패널 높이 및 스크롤은 유지한다.
범례 접기는 레이어 토글을 호출하지 않으며 새 API 요청을 만들지 않는다.
