# 필지별 용도지역 조회

POINT 선택 성공 시 landUse 전용 로더가 기존 sandbox JSONP로 첫 페이지를 조회한다.
PNU, 페이지1, 페이지 크기1000, 전체/반환 건수를 검증한다. 자동 재시도와 추가 페이지 조회는 없다.
API 봉투는 실제 확인된 landUses를 사용한다. resultCode/resultMsg의 공식 성공값이 아직
확정되지 않았으므로 둘 다 비어 있는 데이터 응답만 허용하며, 다른 값은 미확인 오류로 차단한다.
서버 오류 원문은 표시하지 않는다. 브라우저 sandbox 전송은 별도 실측이 필요하다.

제한된 분류 목록은 UQA01X 도시지역, UQA121 제1종일반주거지역, UQA122 제2종일반주거지역이다.
공식 SLD 및 기존 실측에 근거한 초기 목록이며 전국 전체 코드북이 아니다.
포함/저촉만 요약하고 접함은 제외한다. 관계 코드와 반환 명칭이 다르면 미확인 처리한다.
다른 코드는 시설인지 다른 용도지역인지 임의 분류하지 않고 미확인 상태를 남긴다.
화면 요약은 코드별로 합치되 관계를 보존하고, 세부 코드가 있으면 도시지역 요약을 생략한다.
원본 레코드는 별도 배열에 보존한다. 등록일과 갱신일을 고시일/효력일로 해석하지 않는다.
면적과 비율은 생성하지 않는다.

새 선택/닫기/OFF는 기존 세대 번호와 AbortSignal로 늦은 응답을 차단한다.
지도 이동과 WMS 전환은 용도지역 속성을 재조회하지 않는다.
테스트는 외부 통신을 모의 처리하며 브라우저 인증/렌더링을 보장하지 않는다.

## 주요 코드 확장 및 근거

공식 스마트도시계획 [표 2-2-20]의 코드/명칭 대응을 대조했다.
https://smartcity.go.kr/wp-content/uploads/2019/08/대전광역시-스마트도시계획안.pdf
추가 목록: UQA111/112/123/130/210/220/230/240/310/320/330/410/420/430,
UQB001/100/200/300, UQC001, UQD001. 기존 UQA121/122 유지.
UQA01X는 이 표의 UQA001과 동일 코드로 바꾸지 않고 기존 API 실측 코드로 유지한다.
API 실측된 용도지역 코드는 UQA01X/UQA121/UQA122이며 나머지는 문서 근거다.
이전의 3개 코드 제한 설명은 본 절의 확장으로 대체한다.

비대상 제외 목록은 이전 승인 XML 응답에서 확인한 정확한 코드/명칭 쌍에 한정한다.
전국 시설/규제 코드 전체 목록이 아니며 접두사로 제외하지 않는다.
미확인 코드, 코드/명칭 불일치, 관계 불일치, 인식 접함, 비대상 건수를 분리한다.
상위 생략은 도시/관리의 명시적인 자식 코드와 동일 관계일 때만 수행한다.
원본은 보존한다. 안내는 실제 법적 용도지역 부재를 의미하지 않는다.

## 분류 엔진 1차

regulationDictionary.ts에 기존 용도지역 23개와 표시 비대상 15개를 이동했다.
기존 summary/diagnostics의 의미는 유지하며 classified만 추가했다.
각 결과는 recordIndex와 records 배열의 동일 객체 참조를 가지므로 관리번호가 다른
원본을 합치거나 삭제하지 않는다. 저장/내보내기 시에는 PNU·관리번호·원본 순번과
사전 버전을 함께 기록할 수 있다. 객체 참조 자체는 직렬화 후 유지되지 않는다.

사전은 code/acceptedNames/category와 선택적 subtype/legalBasis/legalSource,
출처·버전·확인일·코드검증·법적유형검증·관할·상위코드를 표현한다.
legalVerification=documented-type은 공개 문서의 유형 확인이며, 개별 필지의
현재 유효한 법적 지정이나 인허가 판단을 보장하지 않는다.

공식 문서 근거 용도지역은 official-code-and-type, 도시지역 UQA01X와 기존 비대상은
api-observed-only로 구분한다. UQA01X의 기존 zoning 분류는 호환성을 위한 것이며
법적 근거 검증 상태는 unverified다. 비대상15개는 category=unclassified로 남긴다.
용도지구/용도구역/시설/기타 유형은 모델에만 있고 이번에 임의 배정하지 않았다.
코드·명칭 또는 관계 불일치는 issues로 보존하고 분류 미확인 처리한다.
부분조회는 배치의 partial, 조회실패는 기존 LandUseState.error로 구분한다.
UI·전송·취소·가격계산은 변경하지 않았다.

## 공식 사전 2차 보강

verification은 officialCode/apiObservation/legalType 세 축을 독립적으로 기록한다.
각 축은 상태, 문서명, URL, 버전, 조사 확인일, 확인내용과 한계를 가진다.
checkedAt=2026-11-09는 조사일이며 시행일·지정일·갱신일이 아니다.
기존 codeVerification/legalVerification은 호환성을 위해 유지한다.

UQQ810은 국토계획/구역 코드표의 도시자연공원구역, 기존 API의 같은 코드/명칭,
국토계획법 제38조의2의 지정 유형을 교차 대조해 category=zone으로 연결했다.
공식 코드표는 flSeq=154497349, 법적 근거는 사전 legalSource에 기록한다.
getLandUseAttr 전용 현행 코드북은 여전히 미확보다. 개별 필지의 지정 효력을 보장하지 않는다.

UQF110/UQJ100/UQJ200/UQJ300/UDV100/UQQ500은 공식 공간정보 코드 후보다.
API 실측과 현행 법적 유형·유효성은 미확인으로 기록하며 category=unclassified를 유지한다.
UQT600은 같은 도시자연공원구역 명칭이지만 국토계획/공간시설 레이어의 별도 코드다.
UQQ810과 자동 별칭 통합하지 않는다. 공식 코드표의 개정일은 미확인으로 명시한다.

기존 비대상15개 중 UQQ810만 유형을 승격했고 나머지14개는 API 실측만 보존한다.
용도지역 summary/진단/UI와 원본참조·관리번호·부분조회 처리는 그대로다.
새 classified는 official-code-only도 구분하며 후보 응답이 왔다고 API 실측 사전이나
법적 검증 상태를 자동 변경하지 않는다. 다음 UI에서는 검증 축·관계·부분조회를 함께
확인하고 미분류 결과를 규제 없음으로 해석하지 않아야 한다.

## 공식 사전 3차 보강

UQA001 도시지역을 UQA01X와 별도 코드로 추가한다. 기존 23개 목록과 원본 코드는
유지하며 두 상위 코드는 동일 관계의 명시적 세부 용도지역이 있을 때만 요약에서 생략한다.
UQF130 시가지경관지구는 district, UQQ300 지구단위계획구역은 other-designation이다.
UQQ300을 법정 용도구역으로 해석하거나 UQQ321/UQQ329의 부모로 지정하지 않는다.
확정된 비용도지역 코드의 정확한 명칭·관계는 기존 용도지역 미확인 집계에서 제외한다.

공식 근거는 CODIL 토지종합정보망 도면데이터베이스 구축지침의 검색 색인이다.
https://www.codil.or.kr/filebank/moctroadguide/LU/CIKCLU214056/CIKCLU214056.pdf
직접 PDF 재확인은 HTTP 502로 실패했다. 문서 기준일, 현행 API 전용 코드북 및
전국 적용성은 미확인이다. 법적 유형의 조문과 URL은 사전의 독립 검증 축에 기록한다.
사용자 브라우저 관측 PNU는 4311311400101390003, 4311311500115600000이며
이번 구현에서 API를 재호출하지 않았다. 조사일은 지정일 또는 법령 시행일이 아니다.
UOA110/UMZ100/UQQ321/UQQ329는 미분류 유지. 기존 UOA110 비대상 집계의
하위 호환성은 유지하지만 classified에서는 미분류이며 규제 부재를 의미하지 않는다.
