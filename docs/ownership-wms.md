# 토지소유구분도 WMS 및 모바일 UI

운영 경로는 V-World 전용 getPossessionWMS 이미지다. key/domain/crs/bbox/width/height/format만
전달하며 표준 WMS 레이어·스타일 파라미터를 추정해 추가하지 않는다.
원본 색상·알파와 opacity 1을 유지하고 최대512픽셀 이미지에 화면 bbox를 대응시킨다.
최초OFF, 이동 완료350ms 후 갱신, 이동 시작/OFF 시 채움 제거·예약 취소·늦은 이벤트 차단이다.
소유35·지적40·선택50 순서다. 기존 필지 속성·공시지가 요청은 변경하지 않는다.

공식 색상 범례는 미확보다. 추정 색상표를 게시하지 않고 공식 범례 확인 중 및
지도 색상만으로 소유권을 확정하지 말라는 안내를 제공한다. 지번·면적 라벨 및
축척별 표시 제한은 서버 스타일에 따른 미해결 제약이다.
브라우저 이미지 오류만으로 인증 XML·네트워크 실패를 세부 구분하지 못한다.

모바일900px 이하에서 검색·레이어 도구와 범례는 기본접힘, 긴 설명은 도움말이다.
44px 터치높이, safe-area, 하단 스크롤 필지 패널을 사용한다. PC는 도구를 펼친다.
320/375/390/430/768px 조건 테스트는 모의 상태/정적CSS 검사이며 실기기 검증을 대신하지 않는다.

미배포 변경은 작업 트리에 보존하며 함께 커밋하지 않는다.
