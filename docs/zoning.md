# 용도지역 WMS 1차 구현

검증된 GetCapabilities와 작은 GetMap 응답을 기준으로 `https://api.vworld.kr/req/wms`,
WMS 1.3.0, EPSG:3857, PNG를 사용한다. 도시지역 `lt_c_uq111`, 관리지역 `lt_c_uq112`,
농림지역 `lt_c_uq113`, 자연환경보전지역 `lt_c_uq114`를 선택하며 각각 같은 ID의 기본 스타일을 사용한다.

최초 OFF, ON 시 선택한 분류를 하나의 TileWMS 소스로 조합한다. 모든 분류를 해제하면 레이어를 숨긴다.
초기 불투명도는 55%이며 UI에서 조절한다. 이는 앱의 표시 설정이며 공식 제한이 아니다.
레이어 순서는 배경지도 위 20, 기존 지적 경계 40·선택 강조 50 아래다.
새 지도 객체·클릭 리스너·필지 속성 조회는 추가하지 않는다.

키·domain은 기존 설정을 재사용하며 전체 URL과 원본 오류 응답은 출력하지 않는다.
일반 이미지 로딩을 사용하고 crossOrigin은 지정하지 않는다. CORS가 필요한 fetch·이미지 내보내기·픽셀 읽기는 보장하지 않는다.
분류 변경 이전의 타일 이벤트는 소스 키로 구분한다. OFF 시 표시·상태 갱신을 중단하고, 해제 시 레이어와 리스너를 제거한다.
이미 시작된 이미지 요청의 네트워크 중단은 보장하지 않는다. 별도 자동 재시도는 추가하지 않는다.
실패 안내는 현재 표시 설정을 시작한 이후의 누적 실패이며 현재 모든 타일이 실패했다는 의미가 아니다.

범례 URL·정확한 스타일 색상·지원 축척은 미확인이다. 임의 범례·공식 줌 제한을 추가하지 않았다.
WMS 한 타일이 피처 전체 목록이나 데이터 완전성을 증명하지 않는다.
모바일은 필지 패널이 열리면 겹침을 줄이기 위해 용도지역 컨트롤을 숨기며, 필지 패널을 닫으면 다시 표시한다.

오프라인에서는 요청 URL 구성, UI, 레이어 상태·정리 및 기존 회귀 테스트를 검증한다.
실제 브라우저에서 복수 레이어 조합, 인증, 이미지 정합성, 로딩 오류, 모바일 배치는 별도 승인이 필요하다.
PNU 속성·용도지구·교차면적·사용자 스타일은 이번 구현 대상이 아니다.
