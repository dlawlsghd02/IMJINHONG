# 용도지역 공식 범례

`/req/image`의 `service=image`, `version=2.0`, `request=GetLegendGraphic`,
`type=ALL`, `format=png`를 사용한다. 선택한 네 용도지역 ID와 같은 단수형
`layer`, `style`을 지정하고 기존 키와 선택적 domain을 재사용한다.
인증 URL은 로그나 저장소에 기록하지 않는다.

최초에는 접혀 있으며, 실제 펼칠 때 선택된 레이어의 이미지만 생성한다.
동일 컨트롤 생명주기 안에서는 이미지 요소를 재사용한다. 지도 이동은 범례에
연결하지 않는다. 실패 이미지도 자동 재요청하지 않는다. 페이지 재접속 이후의
재사용은 서버와 브라우저의 HTTP 캐시 정책에 따르며 영구 저장은 하지 않는다.

모바일에서 범례를 펼치면 선택 패널만 접는다. 선택 패널을 다시 펼치면 범례를
접는다. 이 동작은 WMS 설정과 투명도 콜백을 호출하지 않는다. 전체 OFF 또는
전체 체크 해제 시 범례를 숨기며, 재활성화 후 버튼으로 다시 펼칠 수 있다.
모바일 필지정보 패널 표시 중에는 기존 컨트롤 숨김 규칙을 그대로 따른다.

공식 PNG의 비율과 모든 항목을 보존하며 재그리기나 항목 병합은 하지 않는다.
일반 이미지 방식이므로 crossOrigin 또는 fetch 우회는 추가하지 않았다.
이미지 load/error와 자연 크기로 표시 성공을 판단한다. 이미지 error만으로
HTTP 오류 코드, 인증, CORS, 디코딩 실패를 확정할 수 없어 일반 안내를 표시한다.

## 검증 상태

소스와 오프라인 테스트 작성 단계이다. 테스트 실행·타입 검사·빌드 및 이번 UI의
브라우저 인증/렌더링 검증은 별도 승인이 필요하다. 브라우저 검증 시 네 크기
(320×568, 390×844, 844×390, 1280×800), 키보드 포커스, 패널 겹침,
이미지 오류, 선택값/투명도 보존과 재펼침 시 요청 재발생 여부를 확인한다.
캐싱·재배포 이용조건은 추가 확인이 필요하다.
