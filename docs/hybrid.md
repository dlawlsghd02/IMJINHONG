# 위성지도 명칭 오버레이

기존 Base/Satellite 전환과 독립적인 Hybrid XYZ 레이어를 사용한다.
키가 경로에 포함되는 기존 WMTS 인증과 `{z}/{y}/{x}` 체계를 재사용하며
domain 또는 JSONP 설정은 변경하지 않는다. URL과 인증정보를 로그에 남기지 않는다.

명칭 기본값은 ON이지만 최초 일반지도에서는 레이어와 명칭 버튼 모두 숨긴다.
위성지도에서만 명칭 버튼을 제공하고, 일반지도로 전환해도 마지막 선택을 보존한다.
OFF는 레이어를 숨겨 새 렌더 요청을 막는다. 이미 진행 중인 타일 전송까지
취소하는 기능은 없으며, OFF 중 도착한 이미지가 지도에 표시되지는 않는다.
자동 재시도는 추가하지 않는다. 기존 타일 다시 요청 버튼은 베이스맵에만 적용한다.

명칭 zIndex는 30으로 용도지역(20) 위, 지적 경계(40)·선택(50)·마커(100) 아래다.
위성영상과 동일한 EPSG:3857 XYZ 그리드 및 기존 네이티브 줌 범위 5~18을 사용한다.
상위 줌에서는 소스 타일 확대 표시가 발생할 수 있으며 실제 가독성은 미검증이다.

실패는 위성영상과 독립적으로 누적 안내한다. OFF/일반지도에서는 명칭 오류 안내를
숨기고 ON 시 기존 실패 횟수를 다시 표시한다. HTTP·인증·네트워크 오류 구분은
일반 이미지 이벤트만으로 보장하지 않는다.

현재는 소스와 오프라인 테스트 작성만 완료한 상태다. 실행 검증은 별도 승인 후
진행한다. 브라우저에서 인증·영상 정합성·명칭 가독성·좁은 화면 컨트롤 겹침,
OFF 이후 추가 전송 여부, BOX/POINT/용도지역/범례 상태 보존을 확인해야 한다.
